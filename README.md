Evrotrust is a European qualified trust service provider (QTSP) under eIDAS offering remote qualified electronic signatures (QES), an EU-notified electronic identification (eID) scheme for KYC/AML-compliant customer verification, electronic timestamps, electronic registered delivery and free validation of electronic signatures and seals. It serves financial services, public sector, telecom, insurance, healthcare, education and iGaming, and publishes developer documentation, an API reference and a Web SDK at docs.evrotrust.com.

**Areas:** Company · Trust Services · Electronic Signatures · Digital Identity · eIDAS · KYC · Identity Verification · Timestamping · Compliance
