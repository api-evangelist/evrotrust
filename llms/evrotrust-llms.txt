## API Reference: Callback
- [e-Signatures ](https://docs.evrotrust.com/reference/e-signatures.md): Webhook Notifications for e-Signature Workflows.
  - [Document Ready](https://docs.evrotrust.com/reference/readydocument.md): Shows the document status. The callback is triggered on Signed, Rejected, Expired, Failed, Withdrawn and Failed face recognition statuses.<br/><br/>"status": 1 - Pending, 2 - Signed, 3 - Rejected, 4…
  - [Document Group Ready](https://docs.evrotrust.com/reference/readygroupdocument.md): Shows the document group status. The callback is triggered on Signed, Rejected, Expired, Failed, Withdrawn and Failed face recognition statuses.<br/><br/>"status": 1 - Pending, 2 - Signed, 3 -…
  - [One-time Signing Document Ready](https://docs.evrotrust.com/reference/readydocumentoffline.md): Shows the one-time sign document status. The callback is triggered on Signed, Rejected, Expired, Failed and Withdrawn statuses.<br/><br/>"status": 1 - Pending, 2 - Signed, 3 - Rejected, 4 - Expired,…
  - [One-time Signing Document Group Ready](https://docs.evrotrust.com/reference/readygroupofflinedocument.md): Shows the one-time sign document group status. The callback is triggered on Signed, Rejected, Expired, Failed and Withdrawn statuses.<br/><br/>"status": 1 - Pending, 2 - Signed, 3 - Rejected, 4 -…
  - [One-time Signing Certificate Hash Ready](https://docs.evrotrust.com/reference/readyofflinehashcertificate.md): One-time signing certificate hash ready. Valid status values:<br/>"status": 2 - Active, 3 - Blocked, 4 - Revoked. The callback is triggered only on Active status.<br/>
  - [Check Identification Status](https://docs.evrotrust.com/reference/user-identification-status.md)
